# `@bedform/api-docs-generator`

Bedform's counterpart to [`@minecraft/api-docs-generator`](https://www.npmjs.com/package/@minecraft/api-docs-generator).

It re-exports all of `@minecraft/api-docs-generator`, which it installs at exactly that version.
Bedform adds its extensions here, and where an extension replaces a first-party export, it shadows it.

## Versions

This package's version is the version of `@minecraft/api-docs-generator` that it tracks, followed by a channel suffix:
`-dev.N` on the `Master` branch and `-beta.N` on the `Beta` branch. For example, this release tracks
`@minecraft/api-docs-generator@2.4.1`.
