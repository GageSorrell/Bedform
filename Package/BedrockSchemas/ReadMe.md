# `@bedform/bedrock-schemas`

Bedform's counterpart to [`@minecraft/bedrock-schemas`](https://www.npmjs.com/package/@minecraft/bedrock-schemas).

It re-exports the declarations of `@minecraft/bedrock-schemas`, which it installs at exactly that version.
Bedform adds its extensions here, and where an extension replaces a first-party export, it shadows it.

## Versions

This package's version is the version of `@minecraft/bedrock-schemas` that it tracks, followed by a channel suffix:
`-dev.N` on the `Master` branch and `-beta.N` on the `Beta` branch. For example, this release tracks
`@minecraft/bedrock-schemas@1.26.60`.
