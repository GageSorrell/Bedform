# `@bedform/math`

Bedform's counterpart to [`@minecraft/math`](https://www.npmjs.com/package/@minecraft/math).

It re-exports all of `@minecraft/math`, which it installs at exactly that version.
Bedform adds its extensions here, and where an extension replaces a first-party export, it shadows it.

## Versions

This package's version is the version of `@minecraft/math` that it tracks, followed by a channel suffix:
`-dev.N` on the `Master` branch and `-beta.N` on the `Beta` branch. For example, this release tracks
`@minecraft/math@2.4.1`.
