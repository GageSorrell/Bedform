# `@bedform/markup-generators-plugin`

Bedform's counterpart to [`@minecraft/markup-generators-plugin`](https://www.npmjs.com/package/@minecraft/markup-generators-plugin).

It re-exports all of `@minecraft/markup-generators-plugin`, which it installs at exactly that version.
Bedform adds its extensions here, and where an extension replaces a first-party export, it shadows it.

## Versions

This package's version is the version of `@minecraft/markup-generators-plugin` that it tracks, followed by a channel suffix:
`-dev.N` on the `Master` branch and `-beta.N` on the `Beta` branch. For example, this release tracks
`@minecraft/markup-generators-plugin@2.3.3`.
