# `@bedform/core-build-tasks`

Bedform's counterpart to [`@minecraft/core-build-tasks`](https://www.npmjs.com/package/@minecraft/core-build-tasks).

It re-exports all of `@minecraft/core-build-tasks`, which it installs at exactly that version.
Bedform adds its extensions here, and where an extension replaces a first-party export, it shadows it.

## Versions

This package's version is the version of `@minecraft/core-build-tasks` that it tracks, followed by a channel suffix:
`-dev.N` on the `Master` branch and `-beta.N` on the `Beta` branch. For example, this release tracks
`@minecraft/core-build-tasks@5.7.1`.
