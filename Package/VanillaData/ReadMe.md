# `@bedform/vanilla-data`

Bedform's counterpart to [`@minecraft/vanilla-data`](https://www.npmjs.com/package/@minecraft/vanilla-data).

It re-exports all of `@minecraft/vanilla-data`, which it installs at exactly that version.
Bedform adds its extensions here, and where an extension replaces a first-party export, it shadows it.

## Versions

This package's version is the version of `@minecraft/vanilla-data` that it tracks, followed by a channel suffix:
`-dev.N` on the `Master` branch and `-beta.N` on the `Beta` branch. For example, this release tracks
`@minecraft/vanilla-data@1.26.60`.
