# `@bedform/creator-tools`

Bedform's counterpart to [`@minecraft/creator-tools`](https://www.npmjs.com/package/@minecraft/creator-tools).

`@minecraft/creator-tools` is a command-line package, so this package installs it but exports nothing yet.
Bedform adds its extensions here, and where an extension replaces a first-party export, it shadows it.

## Versions

This package's version is the version of `@minecraft/creator-tools` that it tracks, followed by a channel suffix:
`-dev.N` on the `Master` branch and `-beta.N` on the `Beta` branch. For example, this release tracks
`@minecraft/creator-tools@0.21.0`.
