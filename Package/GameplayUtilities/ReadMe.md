# `@bedform/gameplay-utilities`

Bedform's counterpart to [`@minecraft/gameplay-utilities`](https://www.npmjs.com/package/@minecraft/gameplay-utilities).

It re-exports all of `@minecraft/gameplay-utilities`, which it installs at exactly that version.
Bedform adds its extensions here, and where an extension replaces a first-party export, it shadows it.

## Versions

This package's version is the version of `@minecraft/gameplay-utilities` that it tracks, followed by a channel suffix:
`-dev.N` on the `Master` branch and `-beta.N` on the `Beta` branch. For example, this release tracks
`@minecraft/gameplay-utilities@1.3.1`.
