Experimental fixtures for `MineCraft-9a8v.1`, following [the specification](../../Plan/Bedform_Docs_Plan.md). This is a probe, not the documentation renderer or a production change to BedformCommon. The issue remains in progress until the real-client gates pass, including both pack orders and keyboard/controller input.

Run from the repository root:

```powershell
npm run check --workspace @sorrell/documentation-probe
```

The build launches three separate Node processes. `Tool/Build.mjs alpha` reads only `Fixture/alpha.json`; `beta` reads only `Fixture/beta.json`. Neither reads the other pack or a combined search index. `common` generates an isolated shared shell. `Tool/Worlds.mjs` assembles the resulting archives without editing their contents. Each contribution uses a distinct UI file and namespace, and attempts to append an entry to the common registration panel through `modifications`. Native merging is a gate, not a host-test conclusion.

## Mechanisms and concrete limits

Search compiles the concatenated title, heading and body into one transparent1x1 native text-label state per corpus character. A view binding computes the remaining query for the next state. For indexed `a`, its expression is equivalent to:

```text
(((('\uE100' + remaining) - '\uE100a') - '\uE100A') - '\uE100')
```

Under first-occurrence string subtraction, this removes only a leading `a` or `A`. The final empty remainder means a subsequence match. This is linear in corpus characters per binding evaluation sweep; the client may need multiple frames to propagate the chain. The evaluator test checks the **emitted expressions** against an independent oracle, assuming those subtraction semantics. It does not establish native subtraction semantics, view-binding scope, update order, or hidden/zero-size-control evaluation. All need client evidence.

The fixture index rejects non-printable ASCII and apostrophes; queries exclude the private-use sentinel and have a 256-character edit limit. Unicode case folding, ranking, excerpts, descriptions under controller focus, no-results messaging and production-scale responsiveness are not implemented/proven. There are 59 Alpha and 64 Beta character steps. The generated `.metrics.json` files record actual compressed size, uncompressed size, step count and SHA-256 for each build. Do not extrapolate these tiny fixtures to full documentation packs.

Local edit-box state and prefill are candidates, not demonstrated APIs. Routing radio groups use fixed indices 0/1/2; availability attempts to read a contribution marker and defaults absent targets to false. Missing-source behavior and radio state sharing require observation. Source-control lookup across contribution/scroll scopes may fail and must be fixed or reported. The shell uses a plain panel and hides the underlying inventory stack; global inventory mappings and controller focus remain unverified. Modal capture was removed after the observed 1.0.1 input trap, and outer input-panel handling was removed in 1.0.4 after the later close failure. The documentation visibility radio group is separate from page routing.
